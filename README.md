# pcsx2_cheats
This repo is to control cheats which get distributed with PCSX2 builds.

# We do not create or fix cheats
If you have an issue with a cheat not doing quite what you hoped, please find the original author on the forums or otherwise. We only supply the cheats with the emulator.
If the cheat breaks the game in some way however, please make an issue so we can disable the cheat.
